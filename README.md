# Quit Vaping Counter

A simple counter showing how many days, hours, and minutes it's been since you last vaped.

- Press **Start counting** to record the time of your last vape.
- The counter keeps going across page reloads and browser restarts. The start time is saved in `localStorage`.
- Press **Reset** to clear it and start over.

## Run / deploy

Open `index.html` in a browser, or deploy the folder to any static host (GitHub Pages, Netlify, Vercel, etc.). There's no build step.

Note: `localStorage` is per browser and per device, so your saved time won't sync between your phone and your laptop.
